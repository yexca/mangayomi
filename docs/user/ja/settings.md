# 設定

## ライブラリ

すべてのライブラリが、作品数、フォルダー、最終スキャン日時とともに一覧表示されます。ここから **Add library**（ライブラリを追加）、**Scan all**（すべてスキャン、ライブラリが複数ある場合）、個別のライブラリのスキャン、**Edit**（編集）、**Remove library**（ライブラリを削除）を行えます。詳しくは[ライブラリとスキャン](libraries.md)を参照してください。

## リーダーの既定値

リーダーで使用されるページレイアウト、表示サイズ、**Show first page alone**（最初のページを単独で表示）の各オプションです。これらはこのブラウザーに保存され、リーダー自体の設定パネルと同じ設定です。詳しくは[読む](reader.md)を参照してください。

## 外観

- **Theme**（テーマ）：**System**（システム）、**Light**（ライト）、**Dark**（ダーク）。リーダーは常にダークテーマで表示されます。
- **Language**（言語）：インターフェースの言語です。現在は英語のみに対応しています。

どちらもこのブラウザーに保存されます。

## アカウント

- **Change password**（パスワードを変更）：現在のパスワードと、6 文字以上の新しいパスワードを入力します。ほかのデバイスはサインアウトされますが、このデバイスはサインインしたままです。
- **Sign out**（サインアウト）：このデバイスのセッションを終了します。

パスワードを忘れた場合は、サーバー側でリセットしてください。詳しくは[トラブルシューティング](../../operations/troubleshooting.md#forgot-the-password)を参照してください。
