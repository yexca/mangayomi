## 製品の基本方針

- ファイルは元の場所に置いたままです。Mangayomi はファイルを読み込むだけで、名前の変更、移動、書き換えは一切行いません。
- Mangayomi がファイルを削除するのは、ユーザーが内容を確認し、2 段階で承認した削除操作の場合だけです。
- 作品のグループ分けは、現在お使いのフォルダー構成によって決まります。
- 同じインスタンスにサインインしているデバイス間では、読書位置が引き継がれます。
