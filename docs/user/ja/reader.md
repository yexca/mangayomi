# 読む

[English](../en/reader.md) · [简体中文](../zh-Hans/reader.md) · [繁體中文](../zh-Hant/reader.md) · [日本語](reader.md) · [한국어](../ko/reader.md)

作品を開き、**Read**（読む）、**Continue · page N**（続きを読む・N ページ）、または **Read again**（もう一度読む）を選択します。リーダーは黒い背景の全画面で開き、前回読むのをやめた位置から再開します。読みかけの作品を最初のページから開くには、**Start over**（最初から読む）を選択します。

## ページのめくり方

| 操作 | Right to left | Left to right |
| --- | --- | --- |
| 画面の左 30% をタップ | 次へ | 前へ |
| 画面の右 30% をタップ | 前へ | 次へ |
| 右にスワイプ | 次へ | 前へ |
| 左にスワイプ | 前へ | 次へ |
| `←` / `→` キー | 次へ / 前へ | 前へ / 次へ |
| `Space` または `Page Down` | 次へ | 次へ |
| `Page Up` | 前へ | 前へ |

画面の中央をタップすると、コントロールの表示と非表示が切り替わります。`Esc` または戻るボタンでリーダーを閉じます。2 本指でページを拡大しているときはスワイプが無視されるため、表示位置を自由に動かせます。

## コントロール

- **上部バー：** 戻る、タイトル、作者とシリーズ、全画面表示（対応している環境のみ）、リーダー設定。
- **下部バー：** 現在のページまたは見開きのページ、任意のページに移動できるスライダー、シリーズ内の前後の作品に移動するボタン。右から左のモードでは、スライダーと作品ボタンが左右反転します。

最後のページの後には読了画面が表示され、シリーズの次の作品、作品の詳細、または最初から読み直すことを選べます。

## リーダー設定

上部バーの設定ボタンを開きます。

- **Reading direction**（読む方向）：**Right to left**（右から左、右綴じ）または **Left to right**（左から右、左綴じ）。このブラウザーで、現在のシリーズ（シリーズがない場合はその作品）ごとに保存されます。ほかのシリーズではライブラリの既定値が使われます。
- **Page layout**（ページレイアウト）：
  - **Single**（単ページ）：1 ページずつ表示します。
  - **Double**（見開き）：2 ページを並べて表示します。並び順は読む方向に従います。
  - **Auto**（自動）：幅 768 px 以上の横向きの画面では見開き、それ以外では単ページで表示します。
- **Fit**（表示サイズ）：**Whole page**（ページ全体）はページ全体を画面に収めます。**Width**（幅）は画面の幅いっぱいに表示し、縦にスクロールします。
- **Show first page alone**（最初のページを単独で表示）：見開きレイアウトで表紙を単独で表示し、以降のページが正しく見開きの組になるようにします。

横長のページは見開きページとして扱われ、常に単独で表示されます。

レイアウト、表示サイズ、表紙のオプションはブラウザー全体に適用され、**Settings → Reader defaults**（設定 → リーダーの既定値）からも設定できます。

## 進捗

現在のページは、ページが表示されて少し経ったとき、アプリがバックグラウンドに移ったとき、リーダーを閉じたときに保存されます。最後のページが表示されると、その作品は読了としてマークされます。進捗はサーバーに保存されるため、ほかのデバイスでも同じページから続きを読めます。

## オフライン時の動作

インストールしたアプリは、最近読んだページ（直近 300 ページ）と表紙をキャッシュします。そのため、接続が一時的に切れても、読んでいた作品は引き続き読み込まれます。ただし、完全なオフラインダウンロード機能ではありません。
