## Libraries

Lists every library with its work count, folder, and last scan. From here you
can **Add library**, **Scan all** (with more than one library), scan one
library, **Edit** it, or **Remove
library**. See [Libraries and scanning](libraries.md).

## Reader Defaults

The page layout, fit, and **Show first page alone** options used by the reader.
They are stored in this browser and are the same settings as the reader's own
settings panel. See [Reading](reader.md#reader-settings).

## Appearance

- **Theme:** **System**, **Light**, or **Dark**. The reader is always dark.
- **Language:** the interface language. English is currently the only one.

Both are stored in this browser.

## Account

- **Change password:** enter the current password and a new one of at least
  six characters. Other devices are signed out; this one stays signed in.
- **Sign out:** ends the session on this device.

If you forget the password, reset it from the server; see
[Troubleshooting](../../operations/troubleshooting.md#forgot-the-password).
