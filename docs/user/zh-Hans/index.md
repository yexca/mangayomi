## 产品原则

- 你的文件原地不动。Mangayomi 只读取文件，从不重命名、移动或改写它们。
- Mangayomi 删除文件的唯一途径，是经过你审阅并分两步确认的删除操作。
- 作品如何分组，由你现有的文件夹结构决定。
- 在同一实例上登录的所有设备之间，阅读进度会自动同步。
