# 浏览与管理作品

[English](../en/managing.md) · [简体中文](managing.md) · [繁體中文](../zh-Hant/managing.md) · [日本語](../ja/managing.md) · [한국어](../ko/managing.md)

## 页面

- **Home**（首页）：**Continue reading**（继续阅读，按最近阅读排序的进行中作品）和 **Recently added**（最近添加）。
- **Library**（漫画库）：列出所有作品，支持按标题、作者和系列搜索，可按状态筛选（**All** 全部、**Unread** 未读、**In progress** 阅读中、**Completed** 已读完），并可按 **Title**（标题）、**Recently added**（最近添加）或 **Recently read**（最近阅读）排序。
- **Series**（系列）：列出所有系列及其封面、作者和已读作品数量。系列页面按自然顺序列出其中的作品，并为第一个未读完的作品提供 **Start reading**（开始阅读）或 **Continue**（继续）。
- **Authors**（作者）：列出所有作者及其系列数和作品数。作者页面会显示其系列以及 **Standalone works**（独立作品，即不属于任何系列的作品）。
- **Work details**（作品详情）：封面、作者和系列链接、阅读进度、页数、大小、类型、所属漫画库、添加日期、磁盘上的位置，以及系列中的上一个和下一个作品。

当你有多个漫画库时，这些页面上会出现一个选择器，可限定为某一个漫画库，或显示 **All libraries**（所有漫画库）。

## 阅读状态

- 没有阅读进度的作品为未读。在阅读器中打开后标记为阅读中；读到最后一页时标记为已读完。
- **Mark as read**（标记为已读）和 **Mark as unread**（标记为未读）可在作品页面、多选模式中使用，也可在系列或作者的菜单中使用（**Mark all as read** 全部标记为已读、**Mark all as unread** 全部标记为未读）。标记为未读会清除已保存的页码。

## 多选

在漫画库页面、系列页面或作者页面上选择 **Select**（选择），然后点击封面进行选择。操作栏会显示已选数量，并提供 **Select all**（全选已加载的作品）、标记为已读、标记为未读以及 **Delete**（删除）。关闭操作栏即可退出选择模式。

## 删除作品

删除会从你的存储中移除文件，且无法撤销。

你可以删除：

- 单个作品：在其页面上使用 **Delete**；
- 所选作品：在多选操作栏中使用 **Delete**；
- 整个系列：在系列菜单中使用 **Delete series…**（删除系列）；
- 某位作者的全部作品：在作者菜单中使用 **Delete all by this author…**（删除该作者的全部作品）。

每次删除都分为两步：

1. **审阅**。列出将被删除的每个压缩包和文件夹，包括完整路径、大小和文件数，以及总计。删除后会变为空的文件夹（例如删除所有卷后的系列文件夹）也会列出，并一并移除。选择 **Continue**（继续）或 **Cancel**（取消）。
2. **确认**。如果删除的是多个作品、一个系列或一位作者的作品，需要输入 `delete`。然后选择 **Delete permanently**（永久删除）。

只有审阅中列出的内容会被删除，即使在此期间出现了新文件也不例外。如果某个文件无法删除（例如因为权限问题），其他文件仍会被删除，并显示失败项。审阅结果在十分钟后失效。

在 **Settings** 中移除漫画库则不同：它只会从 Mangayomi 中移除该漫画库，而不会动你的文件。
