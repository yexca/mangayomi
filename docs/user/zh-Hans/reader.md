# 阅读

[English](../en/reader.md) · [简体中文](reader.md) · [繁體中文](../zh-Hant/reader.md) · [日本語](../ja/reader.md) · [한국어](../ko/reader.md)

打开一个作品，选择 **Read**（阅读）、**Continue · page N**（继续 · 第 N 页）或 **Read again**（重新阅读）。阅读器会以黑色背景全屏打开，并从你上次停下的地方继续。对于正在阅读的作品，**Start over**（从头开始）会从第一页打开。

## 翻页

| 操作 | 从右到左 | 从左到右 |
| --- | --- | --- |
| 点击屏幕左侧 30% 区域 | 下一页 | 上一页 |
| 点击屏幕右侧 30% 区域 | 上一页 | 下一页 |
| 向右滑动 | 下一页 | 上一页 |
| 向左滑动 | 上一页 | 下一页 |
| `←` / `→` 键 | 下一页 / 上一页 | 上一页 / 下一页 |
| `Space` 或 `Page Down` | 下一页 | 下一页 |
| `Page Up` | 上一页 | 上一页 |

点击屏幕中部可显示或隐藏控件。按 `Esc` 或返回按钮可退出阅读器。用双指缩放页面时，滑动操作会被忽略，以便你拖动查看。

## 控件

- **顶部栏**：返回、标题、作者和系列、全屏（如果支持），以及阅读器设置。
- **底部栏**：当前页或当前跨页、可跳转到任意页的滑块，以及切换到系列中上一个和下一个作品的按钮。在从右到左模式下，滑块和作品按钮会镜像显示。

读完最后一页后，完成界面会提供系列中的下一个作品、作品详情或从头开始等选项。

## 阅读器设置

点击顶部栏中的设置按钮：

- **Reading direction**（阅读方向）：**Right to left**（从右到左）或 **Left to right**（从左到右）。该设置会在当前浏览器中针对当前系列保存（若作品不属于任何系列，则针对该作品）；其他系列仍使用漫画库的默认方向。
- **Page layout**（页面布局）：
  - **Single**（单页）：一次显示一页。
  - **Double**（双页）：两页并排显示，顺序取决于阅读方向。
  - **Auto**（自动）：在宽度至少 768 px 的横屏上显示双页，其他情况显示单页。
- **Fit**（适配）：**Whole page**（整页）使页面完整适配屏幕；**Width**（宽度）使页面填满宽度并可纵向滚动。
- **Show first page alone**（首页单独显示）：在双页布局下，让封面单独显示，以使后续页面正确配对。

宽度大于高度的页面会被视为跨页，始终单独显示。

布局、适配和封面选项对整个浏览器全局生效，也可以在 **Settings → Reader defaults**（设置 → 阅读器默认值）中设置。

## 阅读进度

当前页会在页面停稳后不久、应用切换到后台时以及你退出阅读器时保存。显示作品的最后一页时，该作品会被标记为已读完。阅读进度保存在服务器上，因此其他设备可以从同一页继续阅读。

## 离线行为

已安装的应用会缓存最近阅读的页面（最近 300 页）和封面，因此网络短暂中断时，正在阅读的作品仍可继续加载。这并不是完整的离线下载功能。
