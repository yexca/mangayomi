## 漫画库

列出每个漫画库及其作品数、文件夹和上次扫描时间。在这里你可以 **Add library**（添加漫画库）、**Scan all**（全部扫描，有多个漫画库时可用）、扫描单个漫画库、**Edit**（编辑）漫画库，或 **Remove library**（移除漫画库）。请参阅[漫画库与扫描](libraries.md)。

## 阅读器默认值

阅读器使用的页面布局、适配方式以及 **Show first page alone**（首页单独显示）选项。这些设置保存在当前浏览器中，与阅读器自身设置面板中的选项相同。请参阅[阅读](reader.md)。

## 外观

- **Theme**（主题）：**System**（跟随系统）、**Light**（浅色）或 **Dark**（深色）。阅读器始终为深色。
- **Language**（语言）：界面语言。目前仅支持英语。

两者都保存在当前浏览器中。

## 账户

- **Change password**（修改密码）：输入当前密码和一个至少六个字符的新密码。其他设备会被登出，当前设备保持登录。
- **Sign out**（退出登录）：结束此设备上的会话。

如果忘记密码，请在服务器端重置；请参阅[故障排查](../../operations/troubleshooting.md#forgot-the-password)。
