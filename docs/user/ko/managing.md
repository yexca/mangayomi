# 작품 탐색과 관리

[English](../en/managing.md) · [简体中文](../zh-Hans/managing.md) · [繁體中文](../zh-Hant/managing.md) · [日本語](../ja/managing.md) · [한국어](managing.md)

## 페이지

- **Home**(홈): **Continue reading**(이어서 읽기, 읽는 중인 작품을 최근 순으로
  표시)과 **Recently added**(최근 추가)를 보여 줍니다.
- **Library**(라이브러리): 모든 작품을 표시합니다. 제목, 작가, 시리즈를 대상으로
  검색할 수 있고, 상태 필터(**All**, **Unread**, **In progress**,
  **Completed**)와 **Title**, **Recently added**, **Recently read** 기준 정렬을
  제공합니다.
- **Series**(시리즈): 모든 시리즈를 표지, 작가, 읽은 작품 수와 함께 표시합니다.
  시리즈 페이지에는 작품이 자연 정렬 순서로 나열되며, 아직 다 읽지 않은 첫
  작품에 대해 **Start reading**(읽기 시작) 또는 **Continue**(이어서 읽기)를
  제공합니다.
- **Authors**(작가): 모든 작가를 시리즈 수 및 작품 수와 함께 표시합니다. 작가
  페이지에는 해당 작가의 시리즈와 **Standalone works**(시리즈가 없는 단독
  작품)가 표시됩니다.
- **Work details**(작품 상세): 표지, 작가 및 시리즈 링크, 진행 상황, 페이지 수,
  크기, 유형, 라이브러리, 추가한 날짜, 디스크상의 위치, 시리즈의 이전 작품과
  다음 작품을 표시합니다.

라이브러리가 두 개 이상이면 이 페이지들에 선택기가 표시되어, 하나의
라이브러리로 범위를 좁히거나 **All libraries**(모든 라이브러리)를 표시할 수
있습니다.

## 읽음 상태

- 진행 상황이 없는 작품은 읽지 않은 상태입니다. 리더에서 열면 읽는 중으로
  표시되고, 마지막 페이지에 도달하면 완료로 표시됩니다.
- **Mark as read**(읽음으로 표시)와 **Mark as unread**(읽지 않음으로 표시)는
  작품 페이지, 다중 선택, 시리즈 또는 작가 메뉴(**Mark all as read**, **Mark all
  as unread**)에서 사용할 수 있습니다. 읽지 않음으로 표시하면 저장된 페이지가
  지워집니다.

## 다중 선택

Library 페이지, 시리즈 페이지 또는 작가 페이지에서 **Select**(선택)를 선택한
뒤 표지를 탭하여 선택합니다. 작업 바에는 선택한 개수가 표시되며, **Select
all**(모두 선택, 불러온 작품 대상), 읽음으로 표시, 읽지 않음으로 표시,
**Delete**(삭제)를 제공합니다. 바를 닫으면 선택 모드가 종료됩니다.

## 작품 삭제

삭제하면 저장소에서 파일이 제거됩니다. 삭제는 되돌릴 수 없습니다.

삭제할 수 있는 대상은 다음과 같습니다.

- 작품 하나: 작품 페이지의 **Delete**
- 선택한 항목: 다중 선택 바의 **Delete**
- 시리즈 전체: 시리즈 메뉴의 **Delete series…**
- 한 작가의 모든 작품: 작가 메뉴의 **Delete all by this author…**

모든 삭제는 두 단계로 진행됩니다.

1. **검토.** 삭제될 모든 압축 파일과 폴더가 전체 경로, 크기, 파일 수와 함께
   나열되고 합계도 표시됩니다. 삭제 후 비게 되는 폴더(예: 모든 권을 삭제한 뒤의
   시리즈 폴더)도 함께 나열되며 같이 제거됩니다. **Continue**(계속) 또는
   **Cancel**(취소)을 선택합니다.
2. **확인.** 작품이 두 개 이상이거나 시리즈 또는 작가 단위로 삭제하는 경우
   `delete`를 입력합니다. 그런 다음 **Delete permanently**(영구 삭제)를
   선택합니다.

그사이에 새 파일이 생기더라도 검토 단계에서 나열된 항목만 삭제됩니다. 권한
문제 등으로 삭제할 수 없는 파일이 있어도 나머지 파일은 삭제되며, 실패한 항목이
표시됩니다. 검토 결과는 10분 후에 만료됩니다.

**Settings**(설정)에서 라이브러리를 제거하는 것은 이와 다릅니다. 이 경우
Mangayomi에서 라이브러리만 제거되며 파일은 그대로 남습니다.
