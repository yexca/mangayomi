# 읽기

[English](../en/reader.md) · [简体中文](../zh-Hans/reader.md) · [繁體中文](../zh-Hant/reader.md) · [日本語](../ja/reader.md) · [한국어](reader.md)

작품을 열고 **Read**(읽기), **Continue · page N**(이어서 읽기 · N페이지) 또는
**Read again**(다시 읽기)을 선택합니다. 리더는 검은 배경의 전체 화면으로 열리며,
마지막으로 읽던 위치부터 이어집니다. 읽는 중인 작품을 첫 페이지부터 열려면
**Start over**(처음부터)를 선택합니다.

## 페이지 넘기기

| 동작 | Right to left | Left to right |
| --- | --- | --- |
| 화면 왼쪽 30% 탭 | 다음 | 이전 |
| 화면 오른쪽 30% 탭 | 이전 | 다음 |
| 오른쪽으로 스와이프 | 다음 | 이전 |
| 왼쪽으로 스와이프 | 이전 | 다음 |
| `←` / `→` 키 | 다음 / 이전 | 이전 / 다음 |
| `Space` 또는 `Page Down` | 다음 | 다음 |
| `Page Up` | 이전 | 이전 |

화면 가운데를 탭하면 컨트롤을 표시하거나 숨깁니다. `Esc` 키나 뒤로 가기 버튼을
누르면 리더를 나갑니다. 두 손가락으로 페이지를 확대한 동안에는 스와이프가
무시되므로 화면을 이동해 볼 수 있습니다.

## 컨트롤

- **상단 바:** 뒤로 가기, 제목, 작가와 시리즈, 전체 화면(지원되는 경우), 리더
  설정
- **하단 바:** 현재 페이지 또는 페이지 쌍, 원하는 페이지로 이동하는 슬라이더,
  시리즈의 이전 작품과 다음 작품으로 가는 버튼. 오른쪽에서 왼쪽 모드에서는
  슬라이더와 작품 버튼이 좌우 반전됩니다.

마지막 페이지를 넘기면 완료 화면이 나타나며, 시리즈의 다음 작품, 작품 상세
정보, 처음부터 다시 읽기 중에서 선택할 수 있습니다.

## 리더 설정

상단 바의 설정 버튼을 엽니다.

- **Reading direction**(읽기 방향): **Right to left**(오른쪽에서 왼쪽) 또는
  **Left to right**(왼쪽에서 오른쪽). 현재 시리즈(시리즈가 없으면 해당 작품)에
  대해 이 브라우저에 저장되며, 다른 시리즈는 라이브러리 기본값을 그대로
  따릅니다.
- **Page layout**(페이지 레이아웃):
  - **Single**(단일): 한 번에 한 페이지를 표시합니다.
  - **Double**(양면): 두 페이지를 나란히 표시하며, 순서는 읽기 방향을 따릅니다.
  - **Auto**(자동): 너비 768 px 이상의 가로 화면에서는 양면으로, 그 밖에는
    단일로 표시합니다.
- **Fit**(맞춤): **Whole page**(페이지 전체)는 페이지를 화면 안에 맞추고,
  **Width**(너비)는 화면 너비를 채운 뒤 세로로 스크롤합니다.
- **Show first page alone**(첫 페이지 단독 표시): 양면 레이아웃에서 표지를
  단독으로 표시하여 이후 페이지가 올바르게 짝을 이루도록 합니다.

높이보다 너비가 큰 페이지는 펼침 페이지로 간주되어 항상 단독으로 표시됩니다.

레이아웃, 맞춤, 표지 옵션은 브라우저 전체에 적용되며, **Settings → Reader
defaults**에서도 설정할 수 있습니다.

## 진행 상황

현재 페이지는 페이지가 멈춘 직후, 앱이 백그라운드로 전환될 때, 리더를 나갈 때
저장됩니다. 마지막 페이지가 표시되면 작품이 완료로 표시됩니다. 진행 상황은
서버에 저장되므로 다른 기기에서도 같은 페이지부터 이어서 읽을 수 있습니다.

## 오프라인 동작

설치한 앱은 최근에 읽은 페이지(최근 300개)와 표지를 캐시하므로, 연결이 잠시
끊겨도 읽던 작품은 계속 불러올 수 있습니다. 다만 완전한 오프라인 다운로드
기능은 아닙니다.
