# 설정

## 라이브러리

모든 라이브러리가 작품 수, 폴더, 마지막 스캔 시각과 함께 나열됩니다. 여기에서
**Add library**(라이브러리 추가), **Scan all**(모두 스캔, 라이브러리가 두 개
이상일 때), 개별 라이브러리 스캔, **Edit**(편집), **Remove library**(라이브러리
제거)를 할 수 있습니다. [라이브러리와 스캔](libraries.md)을 참고하십시오.

## 리더 기본값

리더에서 사용하는 페이지 레이아웃, 맞춤, **Show first page alone**(첫 페이지
단독 표시) 옵션입니다. 이 브라우저에 저장되며, 리더 자체의 설정 패널과 같은
설정입니다. [읽기](reader.md)를 참고하십시오.

## 모양

- **Theme**(테마): **System**, **Light**, **Dark** 중에서 선택합니다. 리더는
  항상 어두운 테마로 표시됩니다.
- **Language**(언어): 인터페이스 언어입니다. 현재는 영어만 지원합니다.

두 설정 모두 이 브라우저에 저장됩니다.

## 계정

- **Change password**(비밀번호 변경): 현재 비밀번호와 6자 이상의 새 비밀번호를
  입력합니다. 다른 기기는 로그아웃되고, 현재 기기는 로그인 상태가 유지됩니다.
- **Sign out**(로그아웃): 이 기기의 세션을 종료합니다.

비밀번호를 잊은 경우 서버에서 재설정하십시오.
[문제 해결](../../operations/troubleshooting.md#forgot-the-password)을
참고하십시오.
