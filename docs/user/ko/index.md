## 제품 원칙

- 파일은 원래 위치에 그대로 남습니다. Mangayomi는 파일을 읽기만 하며, 이름을
  바꾸거나 옮기거나 다시 쓰지 않습니다.
- Mangayomi가 파일을 삭제하는 경우는 사용자가 두 단계에 걸쳐 검토하고 확인한
  삭제뿐입니다.
- 작품을 묶는 방식은 이미 사용 중인 폴더 구성에 따라 결정됩니다.
- 같은 인스턴스에 로그인한 기기끼리는 읽던 위치가 이어집니다.
