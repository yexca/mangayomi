# 라이브러리와 스캔

[English](../en/libraries.md) · [简体中文](../zh-Hans/libraries.md) · [繁體中文](../zh-Hant/libraries.md) · [日本語](../ja/libraries.md) · [한국어](libraries.md)

라이브러리는 Mangayomi가 색인하는 `/data` 안의 폴더입니다. 예를 들어 만화용
라이브러리와 화집용 라이브러리처럼 여러 개를 만들 수 있습니다. 라이브러리
폴더끼리는 서로 겹칠 수 없습니다.

## 작품으로 인식되는 대상

- `.zip` 또는 `.cbz` 파일 하나가 작품 하나입니다. 확장자를 뺀 파일 이름이
  제목이 됩니다.
- 이미지(JPEG, PNG, GIF, WebP, BMP, AVIF)를 직접 담고 있는 폴더 하나가 작품
  하나입니다. 폴더 이름이 제목이 되며, Mangayomi는 그 하위 폴더는 살펴보지
  않습니다.
- 그 밖의 폴더는 단순한 상위 폴더로 취급되며, Mangayomi는 그 안을 살펴봅니다.

페이지는 자연 정렬 순서를 따르므로 `2.jpg`가 `10.jpg`보다 앞에 옵니다. 숨김
파일과 `@eaDir`, `#recycle` 같은 NAS 시스템 폴더는 무시됩니다.

## 폴더 구조

**Folder structure**(폴더 구조) 패턴은 각 작품 위에 있는 폴더가 무엇을
의미하는지 지정합니다.

| 패턴 | 구성 | 결과 |
| --- | --- | --- |
| `{author}/{series}` | `Author/Series/Vol 01.cbz` | 작가, 시리즈, 제목 |
| `{series}` | `Series/Vol 01.cbz` | 시리즈, 제목 |
| `{author}` | `Author/Title.cbz` | 작가, 제목 |
| 평면(메타데이터 없음) | 모든 구성 | 제목만 |
| 사용자 지정(예: `{ignore}/{author}/{series}`) | `Magazine/Author/Series/Vol 01.cbz` | 첫 번째 단계를 건너뜀 |

`{author}/{series}`를 사용하는 경우:

```text
Author A/
  Series One/
    Vol 01.cbz        -> Author A · Series One · "Vol 01"
    Vol 02/           -> Author A · Series One · "Vol 02"
      001.jpg
      002.jpg
  Oneshot.zip         -> Author A · no series · "Oneshot"
Loose Artbook/        -> no author · no series · "Loose Artbook"
  001.jpg
```

이미지로 채워진 폴더는 패턴상 `{series}`에 해당하는 단계에 있더라도 항상
작품으로 인식되며, 작가나 시리즈로 인식되지 않습니다. 패턴보다 깊은 단계는
무시됩니다.

입력 양식에는 선택한 패턴에 대한 예시 트리가 표시됩니다. **Run
preview**(미리보기 실행)를 선택하면 스캐너가 찾아낼 처음 50개 작품의 제목,
작가, 시리즈, 경로가 표시되므로 저장하기 전에 패턴을 확인할 수 있습니다.

## 제외 폴더

**Add excluded folder**(제외 폴더 추가)를 선택하면 라이브러리 폴더 범위로
제한된 폴더 선택기가 열립니다. 제외한 폴더 안의 모든 항목은 건너뛰며, 그
폴더에서 이미 색인된 작품은 다음 스캔 때 라이브러리에서 제거됩니다(파일
자체는 건드리지 않습니다).

## 기본 읽기 방향

**Right to left**(오른쪽에서 왼쪽)는 일본 만화에, **Left to right**(왼쪽에서
오른쪽)는 페이지 단위로 내보낸 코믹스와 웹툰에 적합합니다. 리더에서 시리즈별로
방향을 바꾸기 전까지는 라이브러리의 모든 작품에 이 기본값이 적용됩니다.

## 스캔

- 라이브러리를 저장하거나 폴더, 패턴, 제외 설정을 변경하면 스캔이 시작됩니다.
- **Scan now**(지금 스캔, 라이브러리 옆의 새로고침 버튼)는 필요할 때 바로
  스캔합니다. **Scan all**(모두 스캔, 라이브러리가 두 개 이상일 때 표시)은 모든
  라이브러리를 스캔합니다.
- **Automatic scan**(자동 스캔)은 1, 6, 12, 24시간마다 스캔을 반복하거나, 자동
  스캔을 하지 않도록(**Manual only**) 설정합니다.

스캔은 증분 방식으로 진행됩니다. 변경되지 않은 파일은 건너뛰고, 변경된 파일은
다시 읽고, 새 파일은 추가하고, 없어진 파일은 제거합니다. 스캔이 진행되는 동안
사이드바와 라이브러리 목록에 지금까지 찾은 작품 수가 표시됩니다.

NAS 공유 폴더가 마운트되지 않은 경우처럼 라이브러리 폴더를 읽을 수 없으면,
스캔은 오류와 함께 중단되고 기존 색인은 그대로 유지됩니다.

## 편집과 제거

- 패턴을 변경하면 작품의 분류 정보가 새로 지정되며, 읽기 진행 상황은
  유지됩니다.
- 폴더를 변경하면 처음부터 다시 시작합니다. 기존 색인과 진행 상황은 삭제됩니다.
- **Remove library**(라이브러리 제거)는 Mangayomi에서 라이브러리와 그 진행
  상황을 제거합니다. 디스크의 파일은 건드리지 않습니다.
