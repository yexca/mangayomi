# 設定

[English](../en/settings.md) · [简体中文](../zh-Hans/settings.md) · [繁體中文](settings.md) · [日本語](../ja/settings.md) · [한국어](../ko/settings.md)

## 漫畫庫

列出所有漫畫庫及其作品數量、資料夾與上次掃描時間。你可以在這裡 **Add library**（新增漫畫庫）、**Scan all**（全部掃描，有多個漫畫庫時顯示）、掃描單一漫畫庫、**Edit**（編輯）漫畫庫，或 **Remove library**（移除漫畫庫）。請參閱[漫畫庫與掃描](libraries.md)。

## 閱讀器預設值

閱讀器所使用的頁面版面配置、縮放方式與 **Show first page alone**（單獨顯示第一頁）選項。這些設定儲存在此瀏覽器中，與閱讀器本身設定面板中的設定相同。請參閱[閱讀](reader.md)。

## 外觀

- **Theme**（主題）：**System**（跟隨系統）、**Light**（淺色）或 **Dark**（深色）。閱讀器一律使用深色。
- **Language**（語言）：介面語言。目前僅提供英文。

兩者都儲存在此瀏覽器中。

## 帳號

- **Change password**（變更密碼）：輸入目前的密碼，以及至少六個字元的新密碼。其他裝置會被登出；目前這台裝置則維持登入。
- **Sign out**（登出）：結束此裝置上的工作階段。

如果忘記密碼，請從伺服器端重設；請參閱[疑難排解](../../operations/troubleshooting.md#forgot-the-password)。
