# 閱讀

[English](../en/reader.md) · [简体中文](../zh-Hans/reader.md) · [繁體中文](reader.md) · [日本語](../ja/reader.md) · [한국어](../ko/reader.md)

開啟一部作品，然後選擇 **Read**（閱讀）、**Continue · page N**（繼續．第 N 頁）或 **Read again**（重新閱讀）。閱讀器會以黑色背景全螢幕開啟，並從你上次停下的地方繼續。**Start over**（從頭開始）則會從第一頁開啟正在閱讀中的作品。

## 翻頁

| 操作 | 由右至左 | 由左至右 |
| --- | --- | --- |
| 點按畫面左側 30% | 下一頁 | 上一頁 |
| 點按畫面右側 30% | 上一頁 | 下一頁 |
| 向右滑動 | 下一頁 | 上一頁 |
| 向左滑動 | 上一頁 | 下一頁 |
| `←`／`→` 鍵 | 下一頁／上一頁 | 上一頁／下一頁 |
| `Space` 或 `Page Down` | 下一頁 | 下一頁 |
| `Page Up` | 上一頁 | 上一頁 |

點按畫面中央可顯示或隱藏控制項。按 `Esc` 或返回按鈕即可離開閱讀器。以雙指縮放頁面時，滑動手勢會被忽略，方便你平移畫面。

## 控制項

- **頂端列**：返回、標題、作者與系列、全螢幕（在支援的環境中），以及閱讀器設定。
- **底部列**：目前的頁面或跨頁、可跳至任意頁面的滑桿，以及切換到系列中上一部與下一部作品的按鈕。在由右至左模式下，滑桿與作品按鈕會左右鏡像。

讀完最後一頁後，完成畫面會提供系列中的下一部作品、作品詳細資料，或從頭開始等選項。

## 閱讀器設定

開啟頂端列的設定按鈕：

- **Reading direction**（閱讀方向）：**Right to left**（由右至左）或 **Left to right**（由左至右）。此設定會在這個瀏覽器中針對目前的系列（若作品不屬於任何系列，則針對該作品）儲存；其他系列仍沿用漫畫庫的預設值。
- **Page layout**（頁面版面配置）：
  - **Single**（單頁）：一次顯示一頁。
  - **Double**（雙頁）：兩頁並排，依閱讀方向排列。
  - **Auto**（自動）：在寬度至少 768 px 的橫向螢幕上顯示雙頁，其餘情況顯示單頁。
- **Fit**（縮放方式）：**Whole page**（整頁）會讓頁面完整符合螢幕；**Width**（寬度）會填滿寬度並可垂直捲動。
- **Show first page alone**（單獨顯示第一頁）：在雙頁版面中讓封面單獨顯示，使後續頁面能正確配對。

寬度大於高度的頁面會被視為跨頁，一律單獨顯示。

版面配置、縮放方式與封面選項對整個瀏覽器全域生效，也可以在 **Settings → Reader defaults**（設定 → 閱讀器預設值）中設定。

## 進度

目前頁面會在停留片刻後、應用程式切換到背景時，以及離開閱讀器時儲存。顯示作品的最後一頁時，該作品會被標記為已讀完。進度儲存在伺服器上，因此其他裝置可以從同一頁繼續閱讀。

## 離線行為

已安裝的應用程式會快取最近閱讀的頁面（最後 300 頁）與封面，因此即使連線短暫中斷，正在閱讀的作品仍能繼續載入。這並不是完整的離線下載功能。
