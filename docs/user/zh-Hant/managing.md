# 瀏覽與管理作品

[English](../en/managing.md) · [简体中文](../zh-Hans/managing.md) · [繁體中文](managing.md) · [日本語](../ja/managing.md) · [한국어](../ko/managing.md)

## 頁面

- **Home**（首頁）：**Continue reading**（繼續閱讀，列出閱讀中的作品，最近的排在最前面）與 **Recently added**（最近新增）。
- **Library**（漫畫庫）：所有作品，可跨標題、作者與系列搜尋，提供狀態篩選（**All**、**Unread**、**In progress**、**Completed**，即全部、未讀、閱讀中、已讀完），並可依 **Title**（標題）、**Recently added**（最近新增）或 **Recently read**（最近閱讀）排序。
- **Series**（系列）：所有系列，顯示封面、作者，以及已讀作品數量。系列頁面會依自然順序列出其作品，並針對第一部尚未讀完的作品提供 **Start reading**（開始閱讀）或 **Continue**（繼續）。
- **Authors**（作者）：所有作者，顯示系列數與作品數。作者頁面會列出其系列以及 **Standalone works**（獨立作品，即不屬於任何系列的作品）。
- **Work details**（作品詳細資料）：封面、作者與系列連結、進度、頁數、大小、類型、所屬漫畫庫、新增日期、在磁碟上的位置，以及系列中的上一部與下一部作品。

當你擁有多個漫畫庫時，這些頁面上會出現選擇器，可限定只顯示單一漫畫庫，或顯示 **All libraries**（所有漫畫庫）。

## 閱讀狀態

- 沒有任何進度的作品為未讀。在閱讀器中開啟後會標記為閱讀中；讀到最後一頁則標記為已讀完。
- **Mark as read**（標記為已讀）與 **Mark as unread**（標記為未讀）可在作品頁面、多選模式，以及系列或作者的選單（**Mark all as read**、**Mark all as unread**）中使用。標記為未讀會清除已儲存的頁面。

## 多選

在 Library 頁面、系列頁面或作者頁面選擇 **Select**（選取），然後點按封面加以選取。操作列會顯示已選取的數量，並提供 **Select all**（全選已載入的作品）、標記為已讀、標記為未讀，以及 **Delete**（刪除）。關閉操作列即可離開選取模式。

## 刪除作品

刪除會從你的儲存空間中移除檔案，且無法復原。

你可以刪除：

- 單一作品：在其頁面上使用 **Delete**；
- 一組選取項目：在多選操作列中使用 **Delete**；
- 整個系列：在系列選單中使用 **Delete series…**（刪除系列）；
- 某位作者的所有作品：在作者選單中使用 **Delete all by this author…**（刪除此作者的所有作品）。

每次刪除都分為兩個步驟：

1. **審閱**：列出所有將被刪除的壓縮檔與資料夾，包含完整路徑、大小與檔案數量，以及總計。會因此變成空資料夾的資料夾（例如刪除所有卷冊後的系列資料夾）也會一併列出並隨之移除。選擇 **Continue**（繼續）或 **Cancel**（取消）。
2. **確認**：若刪除的是多部作品、整個系列或某位作者的作品，需輸入 `delete`，然後選擇 **Delete permanently**（永久刪除）。

只有審閱清單中列出的項目會被刪除，即使在此期間出現了新檔案也一樣。若某個檔案無法刪除（例如權限不足），其他檔案仍會照常刪除，並顯示失敗的項目。審閱結果會在十分鐘後失效。

在 **Settings**（設定）中移除漫畫庫則不同：它只會從 Mangayomi 中移除該漫畫庫，不會動到任何檔案。
