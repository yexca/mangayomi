## 產品原則

- 你的檔案留在原處。Mangayomi 只會讀取它們，絕不重新命名、移動或改寫。
- Mangayomi 移除檔案的唯一途徑，是由你經過兩個步驟審閱並確認的刪除操作。
- 作品如何分組，由你現有的資料夾結構決定。
- 在同一個執行個體上登入的所有裝置之間，閱讀位置會同步跟隨你。
