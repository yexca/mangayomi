ADRs record durable design decisions.

- [ADR-0001: SQLite first](ADR-0001-sqlite-first.md)
- [ADR-0002: Metadata from folder patterns](ADR-0002-folder-pattern-metadata.md)

## When To Add An ADR

Add an ADR when a decision changes long-term architecture, persistence,
deployment, filesystem boundaries, or developer workflow. Routine
implementation details stay in code comments or area docs.
