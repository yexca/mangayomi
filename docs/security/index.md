# Security Documentation

Security guidance is split by audience:

- [Security policy](../../SECURITY.md): supported versions, private
  vulnerability reporting, and scope.
- [Deployment security](../operations/security.md): network exposure,
  authentication, filesystem mounts, and logs.
- [Secure development](../development/security.md): implementation rules for
  paths, deletion, authentication, and reviews.
- [Privacy and data handling](../../PRIVACY.md): stored data and browser
  caches.

Use the security policy to report a vulnerability. Use deployment security when
operating an instance, and secure development when changing the codebase.
